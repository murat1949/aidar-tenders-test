ЦЕЛЬ TEST10N
Сделать работу с Samruk понятной обычному сотруднику без технических терминов
(BAT, bridge, localhost, WinError, Collector mode).

ЧТО СДЕЛАНО
1. Обновлён index.html.
2. Добавлены понятные пользовательские запускающие файлы:
   - Samruk для Aidar Tenders.bat
   - Aidar Tenders - обновление Samruk.bat
3. Скрыты/переведены на понятный язык технические ошибки.

ПРОВЕРЕННЫЕ СЦЕНАРИИ

1. ОБЫЧНАЯ РАБОТА
Samruk открыт, модуль обновления запущен.
Результат:
«Samruk готово. Проверено 2 · Новых 0 · Техспек 0 · Ошибок 0»

2. SAMRUK НЕ ОТКРЫТ
Пользователь получает сообщение:
«Samruk не открыт. Откройте ярлык „Samruk для Aidar Tenders“, войдите в систему и повторите обновление.»

3. МОДУЛЬ ОБНОВЛЕНИЯ НЕ ЗАПУЩЕН
Пользователь получает сообщение:
«Обновление Samruk сейчас не запущено. Откройте ярлык „Aidar Tenders — обновление Samruk“ и повторите.»

4. ТЕХНИЧЕСКИЕ ОШИБКИ
WinError 10061 и другие технические сообщения больше не показываются сотруднику
в сыром виде.

ВАЖНОЕ ЭКСПЛУАТАЦИОННОЕ ПРАВИЛО
Перед обновлением Samruk должна быть открыта только одна рабочая вкладка Samruk
с нужной поисковой выдачей.

Причина: если оставить несколько вкладок Samruk с разными запросами,
сборщик может выбрать не ту выдачу (например, страницу с 1 520 результатами
вместо тестовой выдачи из 2 лотов).

Рекомендуемый порядок работы сотрудника
1. Открыть «Samruk для Aidar Tenders».
2. Оставить одну рабочую вкладку Samruk.
3. Выполнить нужный поиск.
4. Открыть «Aidar Tenders — обновление Samruk».
5. В ProcureVision нажать «Обновить Samruk».
6. Дождаться зелёного сообщения о результате.
