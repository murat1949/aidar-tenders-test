AIDAR TENDERS — TEST10O LOGGING

Что добавлено:
- После каждого обновления Samruk автоматически ведётся локальный журнал.
- Имя файла: SAMRUK_LOG.txt
- Файл создаётся автоматически рядом с bridge.
- Успешный запуск: дата/время, запрос, количество строк, техспеки, ошибки.
- Ошибка: дата/время и понятное сообщение об ошибке.
- Журнал не влияет на работу обновления: если запись журнала не удалась, обновление всё равно продолжается.

Для диагностики:
если у сотрудника возникла проблема, достаточно передать файл SAMRUK_LOG.txt.

Тест:
1. Запустить «Aidar Tenders - обновление Samruk».
2. Выполнить обновление Samruk.
3. Проверить, что рядом появился SAMRUK_LOG.txt.
