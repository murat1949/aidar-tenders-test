PROCUREVISION KZ — PORTAL v4 LIVE

Это уже не тестовая лента внутри HTML.
Портал читает таблицу tenders из существующего Supabase.

КАК ЗАПУСТИТЬ
1. Откройте index.html.
2. Один раз вставьте Publishable / anon key проекта Supabase.
3. Нажмите «Подключить».

ВАЖНО
- Service-role / secret key в портал НЕ вставлять.
- Адрес Supabase уже прописан.
- Publishable key хранится только в LocalStorage браузера.
- Если Supabase ответит ошибкой доступа, просто пришлите скрин. Ничего в базе вручную менять пока не нужно.

Что работает:
- реальные строки из tenders;
- реальные счётчики;
- поиск;
- фильтры по источнику / активности / приоритету;
- карточка закупки;
- исходная ссылка;
- пагинация;
- Samruk отображается как ожидающий авторизацию.
