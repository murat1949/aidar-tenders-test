ЧТО ЗАВЕРШЕНО В TEST10O

1. ЗАЩИТА ОТ НЕСКОЛЬКИХ ВКЛАДОК SAMRUK
Если открыто больше одной вкладки Samruk, обновление не запускается.
Сотрудник получает понятное сообщение:
«Открыто несколько вкладок Samruk. Оставьте одну вкладку с нужным поиском и повторите обновление.»

Проверено:
- две вкладки Samruk → обновление заблокировано;
- одна вкладка Samruk → обновление проходит штатно.

2. ЖУРНАЛ ОБНОВЛЕНИЙ И ОШИБОК
После каждого обновления автоматически ведётся локальный файл:
SAMRUK_LOG.txt

Журнал фиксирует:
- дату и время;
- результат OK или ERROR;
- поисковый запрос;
- количество обработанных лотов;
- количество техспек;
- количество ошибок;
- текст ошибки при сбое.

Проверено:
Успешная запись:
OK | keyword=оргтехника | rows=2 | http=200 | techspec=0 | techspec_existing=1 | errors=0

Запись ошибки:
ERROR | message=Открыто несколько вкладок Samruk...

3. ПОНЯТНЫЕ СООБЩЕНИЯ СОТРУДНИКУ
Технические названия BAT, bridge, localhost, WinError и Collector mode
не используются в пользовательских сообщениях.

ФИНАЛЬНАЯ ИНСТРУКЦИЯ ДЛЯ СОТРУДНИКА

1. Открыть ярлык «Samruk для Aidar Tenders».
2. Войти в Samruk, если система попросит авторизацию.
3. Оставить открытой только одну вкладку Samruk.
4. Выполнить нужный поиск и проверить, что показана нужная выдача.
5. Открыть «Aidar Tenders — обновление Samruk».
6. Открыть ProcureVision.
7. Нажать «Обновить Samruk».
8. Дождаться зелёного сообщения о результате.

ЕСЛИ ПОЯВИЛОСЬ КРАСНОЕ СООБЩЕНИЕ

«Открыто несколько вкладок Samruk»
→ закрыть лишние вкладки, оставить одну с нужным поиском и повторить.

«Samruk не открыт»
→ открыть «Samruk для Aidar Tenders», войти в систему и повторить.

«Обновление Samruk сейчас не запущено»
→ открыть «Aidar Tenders — обновление Samruk» и повторить.

Если проблема не решается:
→ передать ответственному файл SAMRUK_LOG.txt из рабочей папки.
